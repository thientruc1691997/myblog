Story
Two unforgettable days from Hasselt to Leuven

This project is very special to me because it is not only about technology. It is also about the people and the journey behind it.

We travelled from Hasselt to Leuven, and there was a train strike.

During the trip there were many small moments that I still remember. At one point Luis managed to jump onto the train with only about 30 seconds left before the doors closed.

Another memory I always think about is Sadia. She lives in Antwerp, but because the trains were no longer running normally, she came back with us to Hasselt that night. Before that, she had already prepared a very beautiful outfit for the presentation the next day. Because of the travel situation, everything became more complicated than expected.

These small moments made the experience feel very real. It was messy, tiring, funny, and unforgettable at the same time.

Idea
What our project was about

Our idea was to build an AI companion that can support elderly people in daily life. We wanted the system to feel helpful, simple, and human.

Many elderly people need support, but they do not always want a complicated application. So we thought about one assistant that could do several helpful tasks in one place.

  • simple conversation and companionship
  • medication reminders
  • basic health support
  • emergency help
  • vision-based monitoring support
Build
What we managed to build

Even though the project is still unfinished, we already built an early structure for the idea. The repository shows a backend and frontend for the system.

The project uses a FastAPI backend and a React + Vite frontend. It also connects different AI and application components together.

  • chat support for simple communication
  • vision support for monitoring and assistance
  • medication management
  • health dashboard
  • emergency support module
This project page is written in a simple way on purpose. Later, I will add more technical details, screenshots, and prototype sketches.
Technology
Tech stack used in the prototype

The prototype combines a lightweight web architecture with AI and computer vision tools. The goal was to build something functional quickly during the hackathon while keeping the system flexible for future development.

Backend
Python 3.11 · FastAPI · Uvicorn
AI / LLM
Claude API (Anthropic)
Vision
YOLOv8 (Ultralytics) · MediaPipe Pose
Database
SQLite · SQLAlchemy (async)
Frontend
React 18 · Vite
Voice
Web Speech API (browser native)
Realtime
WebSocket

The current prototype already includes the main sections: voicechat, medication reminders, health support, emergency support, and dashboard views.

My next step is to improve the backend and make the whole system more stable and more complete.
